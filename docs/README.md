# Leoxy documentation

- [Leoxy overview](leoxy.md): architecture, routing, endpoints, and basic operation.
- [Configuration reference](configuration.md): settings in `leoxy_config.yaml`, including HTTP, TCP, UDP, security, and watcher options.
- [CLI guide](cli.md): build instructions and foreground/background commands.
- [Docker guide](docker.md): image build, container configuration, Compose, and persistence.
- [Benchmark guide](benchmark.md): benchmark command, flags, output, and heap profiling.
- [Watcher guide](watcher/watcher.md): resource sampling, threshold reports, heap profiles, and webhooks.
